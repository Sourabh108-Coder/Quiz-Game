# 🎯 Quiz Game Project

This is a simple interactive **Quiz Game** built using HTML, CSS, and JavaScript.

## 📌 Features
- Multiple choice questions
- Real-time answer checking
- Score calculation (Right / Wrong)
- Simple and responsive UI
- Instant result display at the end

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 📁 Project Structure
Quizes/
│── quiz.html
│── .gitignore
│── README.md


## 🚀 How to Run
1. Download or clone the repository
2. Open `quiz.html` in any browser
3. Or use **Live Server** in VS Code for best experience
